گنجینهٔ سخن چیست؟

گنجینهٔ سخن یک مجموعه ساخت‌یافته از اشعار و سخنان شاعران کلاسیک فارسی است که برای مطالعه، پژوهش و استفاده در پروژه‌های نرم‌افزاری ارائه شده است.

چه شاعرانی در پروژه وجود دارند؟

داده‌ها شامل ۳۸ شاعر کلاسیک فارسی از جمله رودکی، فردوسی، خیام، عطار، سعدی، مولانا، حافظ، جامی، صائب و بیدل است.

تصاویر شاعران از کجا می‌آیند؟

در صورت وجود تصویر مناسب، وب‌سایت تصویر صفحه مربوط به شاعر را از API ویکی‌پدیای انگلیسی دریافت می‌کند. اگر تصویری پیدا نشود، یک نشان ساده به‌عنوان تصویر جایگزین نمایش داده می‌شود.

آیا وب‌سایت به سرور نیاز دارد؟

خیر. وب‌سایت کاملاً استاتیک است و برای GitHub Pages ساخته شده است. داده‌ها مستقیماً از فایل‌های عمومی پروژه و CDN دریافت می‌شوند.

آیا می‌توانم از داده‌ها در پروژه خودم استفاده کنم؟

بله، اما پیش از بازتوزیع یا استفاده تجاری باید مجوز داده و منابع بالادستی و الزامات attribution را بررسی کنید. جزئیات در مخزن GitHub قرار دارد.
